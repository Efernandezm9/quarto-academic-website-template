# Usually leave this folder alone

- `defaults.yml`: shared Quarto appearance and behavior.
- `styles.css`: fonts, colors, spacing, and responsive layout.
- `new-post.qmd`: copy this into `posts/` to start a new blog post.

The folder starts with `_` so it is clearly separate from your content. It is not a public page. There are no extra extensions, publication spreadsheets, Python scripts, or custom JavaScript to maintain.

For an optional color change, edit `--accent` at the top of `styles.css`. Use a dark color so links remain readable against the light background. You do not need to edit this folder to write your website.

Original template: [Gang He's Quarto Academic Website Template](https://github.com/drganghe/quarto-academic-website-template). Its MIT license remains in the root `LICENSE`. The two example photos are retained from that repository; replace them with your own before publishing your personal site.
